### 🚀 About Me

I am a passionate **Frontend Developer** specializing in building highly interactive and visually responsive web applications. I love pairing clean code practices (TypeScript/JavaScript) with modern utility frameworks (Tailwind CSS) to create websites that wow users. Recently, I've also been exploring **AI-powered web services** and slot-booking platforms.

- ⚙️ **Currently working on:** Crafting beautiful web applications and AI integrated utilities.
- 🌱 **Learning & Exploring:** Advanced Next.js, Node.js server frameworks, and autonomous AI agents.
- 🎯 **Goals:** To write clean, highly reusable UI components and build user interfaces that feel premium and premium-grade.
